# Google Flow character features (Characters, Avatars, Ingredients, custom Voices) as of Nov 13, 2026 (Omni Flash 1.2 era)

Source ranking: official Google Help / flow.google.com / Google blog / AI Studio docs > third-party hands-on. Items marked [snippet only] came from search-result excerpts, not a full page read.

## 1. What are Flow's official character features, exact UI names and workflows?

### Takeaway
Flow has four distinct, officially documented mechanisms: (a) **Characters** (left-nav tab; a reusable bundle of 1-2 images + name + optional voice + optional "Character info"), (b) **Avatars** (your own real face and voice, called with `@me`), (c) **Ingredients** (ad-hoc reference images/videos in the prompt box, "Ingredients to Video"), and (d) **Frames** (start/end frame) plus **Scenebuilder** for sequencing clips. Characters are called in a prompt by typing `@` + the character's name.

### Cited Findings
- Official definition: "You can bundle specific visual and audio references into a single, reusable character. Your character's face, clothing, and voice remain strictly consistent across multiple generations without needing to upload the same images every time." — [Flow Help: Manage projects, assets & collections (Characters section)](https://support.google.com/flow/answer/16935308?hl=en)
- Create flow, Step 1 "Generate your character": go to a project, click **Characters** on the left (click **New Character** if you already have one), describe the character in the prompt box (or pick a pregenerated sample prompt), "Upload or generate 1 or 2 images that show the visual appearance of your character," click Generate. "A character must contain at least one image to be used." — [Flow Help 16935308](https://support.google.com/flow/answer/16935308?hl=en)
- Step 2 "Give your character a name and voice": add a name; click **Select a voice**; "Select a voice or create a custom voice"; click **Add to Character**; optional "Enter your character info"; click **Done**. Edit and Delete exist under Characters. — [Flow Help 16935308](https://support.google.com/flow/answer/16935308?hl=en)
- Asset browser filter categories in a project: All media, Images, Videos, **Characters**, **Scenes**, Uploads. — [Flow Help 16935308](https://support.google.com/flow/answer/16935308?hl=en)
- Using a character in a prompt: "In the prompt box, type `@` followed by your character's name... To add your avatar to your prompt, type `@me`." Example: `@CaptainZoro walking through a futuristic city.` — [Flow Help: Create videos in Google Flow](https://support.google.com/flow/answer/16353334?hl=en&co=GENIE.Platform%3DDesktop)
- Ingredients (separate from Characters): in the prompt box click model name > **Video** > **Ingredients**; drag images/video in, or type `@` to search uploaded project assets by name, or use the Add (+) button. Help text: "You can consistently use the same images for your character and key objects from one clip to the next with the use of ingredients." Tip: "provide subject or product references on a plain or segmented background." — [Flow Help 16353334](https://support.google.com/flow/answer/16353334?hl=en&co=GENIE.Platform%3DDesktop)
- Frames: model name > **Video** > **Frames**; "+ Add start frame" / "+ Add end frame." Note that feature availability may differ by country and certain image types may not be supported. — [Flow Help 16353334](https://support.google.com/flow/answer/16353334?hl=en&co=GENIE.Platform%3DDesktop)
- Hands-on description of the Characters tab (June 2026): Characters tab > New Character; three visual-base routes: Templates (e.g., "the fantastical"), From Scratch (Nano Banana Pro or Nano Banana 2), Upload/Import (upload image, or "import an existing character image from another Google Flow project"). Then an optional second reference image for "different angles" where Flow asks you to describe body/outfit (example "dark navy sweater and cargo pants"). Optional **Character info** (baseline personality, quirks, mannerisms) "feeds directly into the Google Flow Agent." — [Kartaca hands-on guide, Jun 12, 2026](https://kartaca.com/en/mastering-google-flow-the-ultimate-guide-to-character-avatar-creation/) (third-party; "Character info" and Agent link not stated in the official article I read)
- Avatars: "Securely create an avatar in Google Flow, featuring your own highly accurate visual and audio likeness." Profile picture (top right) > **Create avatar** > Get started > scan QR code with phone > follow on-screen instructions; use with `@me`; delete via **Manage avatar** > **Delete avatar**. Avatar data "cannot be shared via Google Flow Tools or public project links" and Flow "runs strict recitation and safety checks on all generated likeness content." — [Flow Help: Create & use your avatar](https://support.google.com/flow/answer/17102997?hl=en). Kartaca adds the process records a selfie video and has you "read a few numbers out loud" and calls Avatar "experimental." — [Kartaca](https://kartaca.com/en/mastering-google-flow-the-ultimate-guide-to-character-avatar-creation/)
- Scenebuilder: "Arrange multiple clips in a sequence," rearrange, trim handles, preview, download. Add a clip via hover > More > **Add to Scene**. Direct YouTube upload only supports individual clips; a Scenebuilder sequence must be downloaded as one file first. — [Flow Help: Edit videos & build scenes](https://support.google.com/flow/answer/16935718?hl=en); [Flow Help 16935308](https://support.google.com/flow/answer/16935308?hl=en)
- Extend: Plus/Pro/Ultra only on Omni Flash 1.2; "You can add up to 3 image references to guide character and environmental consistency." Extended clips cannot use other edit modes (insert, remove, camera). — [Flow Help 16935718](https://support.google.com/flow/answer/16935718?hl=en)
- The flow.google.com plan table lists "Characters", "Avatars", "Scenebuilder", "Ingredients to Video", "Frames to Video", "Agent" among features included even without a subscription (free tier). — [flow.google.com](https://flow.google.com/)
- Naming nuance for the report: "Characters" (reusable entity, `@Name`) and "Ingredients" (raw references) are different things; the voice picker lives under Ingredients > Add > **Voices** and in the Character editor. No feature named "Cast" or "Presets" in Flow's official help (Melius's "Cast" is Melius's own product).

### Inferences
- For a multi-shot series, the cleanest official path is: create one Character per recurring person (1-2 images, name, voice), then call `@Name` in every clip prompt, rather than re-uploading ingredients each time.
- The "1 or 2 images" limit applies to the Flow Character UI; the API's separate "up to 3 images per character" limit (see section 3) is not the same control.

### Gaps
- Official help does not state a maximum number of characters per project or per shot inside the Flow UI (only the API limit; see section 3).
- I did not find official text on whether a Character can be selected at project level in a different project (only that you "open the project that you created your character in" to edit, and a third-party claim that images can be imported from another project).

## 2. Can a voice be created and attached to a character? Reuse across clips; languages (Indonesian?)

### Takeaway
Yes. Flow lets you pick one of preset voices (the April 2026 announcement said 30) or build a **custom voice** from a preset "Base Voice" plus a text description of how to change it, then attach it to a Character (or add it as a `@Voice` ingredient). You cannot upload audio to clone a voice (hands-on), and voice references are only valid on Omni Flash ingredient-based generations. Indonesian voice support is not documented officially.

### Cited Findings
- Voice references purpose: "To maintain a specific character's voice across multiple video clips, add a single-speaker voice reference to your prompt." Steps: model **Omni Flash** > **Video** > **Ingredients** > Add (+) > **Voices** > choose voice (hover for "a 10-second sample preview"); reference directly by typing `@Voice`, example `@Voice: Andrew`. — [Flow Help 16353334](https://support.google.com/flow/answer/16353334?hl=en&co=GENIE.Platform%3DDesktop)
- Create custom voices (quoted steps): model name > **Omni Flash**; Add > **Voices** > **Create New Voice**; "Under 'Base Voice,' select a preset voice"; name it; "Under 'Voice Performance,' describe how to change the voice. For example: 'Make the voice sound slightly raspy with a New York accent.'"; optional "preview an 8-second sample of your custom voice" via "Sample Dialogue"; click Sync; **Save New Voice**. — [Flow Help 16353334](https://support.google.com/flow/answer/16353334?hl=en&co=GENIE.Platform%3DDesktop)
- Models page phrase: Omni Flash exclusive feature "**Create custom voices:** Select a preset voice. Then enter a prompt that describes how you'd like to edit or style it." and "Some Omni features and voice customizations are only available in certain regions." — [Flow Help: Models & supported features](https://support.google.com/flow/answer/16352836?hl=en)
- Guardrail: "You can add voice references only to video generations that use ingredients. For all other kinds of generations, you'll get an error." — [Flow Help 16353334](https://support.google.com/flow/answer/16353334?hl=en&co=GENIE.Platform%3DDesktop)
- Attaching to a Character: Character editor > **Select a voice** > select or create custom > **Add to Character**. — [Flow Help 16935308](https://support.google.com/flow/answer/16935308?hl=en)
- Origin: official Flow X account, Apr 2, 2026: "You can now assign specific voices when selecting ingredients. Choose from 30 distinct options to keep your dialogue and characters consistent across every setting, scene, and action. This experimental feature is currently available to Ultra users." — [Flow on X](https://x.com/FlowbyGoogle/status/2039813897180656015) (dated; the current help page does not restrict voices to Ultra, and the flow.google.com free tier lists Characters)
- No voice cloning from uploaded audio: "Note that you currently cannot upload external audio files to clone a voice; you must build from Flow's templates." — [Kartaca](https://kartaca.com/en/mastering-google-flow-the-ultimate-guide-to-character-avatar-creation/) (third-party, June 2026). Consistent with API docs: "Voice editing is not supported." and "Uploading audio inputs or audio references is unsupported in the current version of the API." — [AI Studio Omni docs](https://aistudio.google.com/docs/omni)
- Your own voice: Avatar captures your voice ("avatar voices" usable as voice reference, per a Facebook-group post on the Omni 1.2 update, [snippet only, weak source](https://www.facebook.com/groups/420460845237600/posts/2137224216894579/)).
- Reuse across clips: Official wording says a voice reference maintains "a specific character's voice across multiple video clips." Omni 1.2 announcement claims "more fluid, natural-sounding dialogue, clearer lip-sync, and distinct multi-speaker conditioning," with a demo where "four character, mouth, and one-second voice references" are routed "to the right character." — [Google blog, Nov 5, 2026](https://blog.google/innovation-and-ai/technology/developers-tools/introducing-gemini-omni-1-2-flash/)
- Languages: Flow UI supports Indonesian (and Javanese, Malay, many others), but "For best results with our tools, we recommend using English prompts"; output quality "may vary depending on the language and complexity of the prompt." — [Flow Help: Where you can use Flow](https://support.google.com/flow/answer/16353544?hl=en). API docs: "English (EN) is fully supported, but other languages have not been evaluated, so they may work but results can vary." — [AI Studio Omni docs](https://aistudio.google.com/docs/omni). A Resemble AI quote in the launch post says speech "sounds natural in every language we tested" (vendor testimonial; languages not named). — [Google blog](https://blog.google/innovation-and-ai/technology/developers-tools/introducing-gemini-omni-1-2-flash/)
- Prompting dialogue: the AI Studio guide says audio is steered in the prompt ("Include calm background music"), recommends "No dialogue" when you want silence, and the third-party Atlas Cloud guide recommends labeled speakers, exact quoted lines, positions and "Keep each voice attached to the same person throughout." — [AI Studio](https://aistudio.google.com/docs/omni); [Atlas Cloud](https://www.atlascloud.ai/blog/tips/gemini-omni-1.2-flash-multi-speaker-dialogue)

### Inferences
- Because custom voices are built from a preset base plus a text description, the saved voice is a stored "voice profile" that stays the same across clips only as far as the model honors it; there is no documented numeric guarantee.
- Writing the dialogue in Indonesian in the prompt may work but is outside the officially tested path; an English-accented base voice may carry an accent. This is an inference, not a documented fact.

### Gaps
- No official list of the preset voice names/count in the current build (30 in April 2026; the help page names "Andrew" as an example), no official statement of which languages/accents each preset voice supports, and no verification of Indonesian speech quality.
- Whether a custom voice is saved per project, per account, or per Character is not stated officially.

## 3. How do creators keep character + voice consistent across shots? Limits and what docs/hands-on guides say

### Takeaway
Official guidance: reuse the same references clip to clip (Characters/Ingredients with `@name`, plus a single-speaker voice reference), keep references clean, avoid conflicting prompt text, and use Extend/multi-turn edit to continue a shot. Hard limits found: Flow Character = 1-2 images; Omni 1.2 API = 6 reference images total (up to 3 images per character, up to 2 characters), 3-15 s clips, extension 3-10 s per turn up to 30 s total.

### Cited Findings
- Limits (API; Flow UI limits per shot are not separately published): "Gemini Omni 1.2 Flash supports up to 6 reference images per request (up to 3 images per character for up to 2 characters) to keep character likeness, attire, and objects consistent across shots." Reference videos: 11-15 s clips support 1 reference video (up to 3 s); 3-10 s clips support up to 3 (3 s each); "any audio in a reference video is ignored." — [AI Studio Omni docs](https://aistudio.google.com/docs/omni)
- Durations: Flow, no subscription: 3-10 s; Plus/Pro/Ultra: 3-15 s; frames-to-video (first+last) 3-10 s. Help page lists 4s/6s/8s/10s Omni Flash generations for YouTube upload context. — [Flow Help: Models](https://support.google.com/flow/answer/16352836?hl=en); [AI Studio](https://aistudio.google.com/docs/omni); [Flow Help 16935308](https://support.google.com/flow/answer/16935308?hl=en)
- Official best practices: "Prepare clean ingredients" (plain/segmented background), "Avoid conflicting guidance" ("Your text prompt should complement, not contradict, your visual inputs"; "A consistent look and feel across all your ingredient images helps the model blend them more effectively."), iterate with Gemini. — [Flow Help 16353334](https://support.google.com/flow/answer/16353334?hl=en&co=GENIE.Platform%3DDesktop)
- Official Flow blog tip: "Before you create a scene, you need your characters and props" (create ingredients first). — [Google blog: 5 tips for Flow](https://blog.google/innovation-and-ai/products/flow-video-tips/) [snippet only]
- Extend rules (API): "10-second lookback window... If a character or visual element only appeared before the final 10 seconds, mention it again in your prompt or pass it as a reference image." "Multi-turn voice extension: Generating spoken dialogue or speech is supported when extending previously generated videos via multi-turn." Cannot extend an uploaded video where someone is talking to add dialogue. Prompt tip: "Show the same characters in the next scene." — [AI Studio Omni docs](https://aistudio.google.com/docs/omni)
- Edit/refine in Flow: up to 3 conversational turns "without losing the context of your previous edits"; edits cost the same credits per second as standard generations. — [Flow Help 16935718](https://support.google.com/flow/answer/16935718?hl=en)
- Omni 1.2 claims "less visual drift or morphing across motion and camera transitions" and "Faces, garments... stay consistent across camera angles." — [Google blog](https://blog.google/innovation-and-ai/technology/developers-tools/introducing-gemini-omni-1-2-flash/)
- Prompt behavior: Omni by default makes multi-shot videos with cuts; for a single scene prompt "In a single continuous shot / No scene cuts." For editing: "Keep everything else the same." — [AI Studio Omni docs](https://aistudio.google.com/docs/omni)
- Third-party comparison (Nov 11, 2026) summarizes Flow as "Ingredients to Video with @CharacterName tags", up to 6 images / 3 per character in the API, 3-15 s, and notes "In the API, Omni Flash takes references for two characters at most, three images each." — [Melius](https://www.melius.com/blog/best-ai-video-generators-consistent-characters) (vendor of a competing product; derived from Google docs)
- Suggested multi-shot workflow from a third party: build a character sheet (3-4 angles, plain background), fix wardrobe/palette and repeat it in every prompt, run a test scene first. — [Melius](https://www.melius.com/blog/best-ai-video-generators-consistent-characters) (generic, not Flow-specific)
- Character styling is flexible while identity is locked: you can still prompt clothing, environment and action changes (hands-on). — [Kartaca](https://kartaca.com/en/mastering-google-flow-the-ultimate-guide-to-character-avatar-creation/)
- Credit costs (Omni Flash 1.2): up to 10 s all users: 360p = 1 credit/second, 720p = 3 credits/second; 11-15 s (Plus/Pro/Ultra only): extra seconds 2 credits/s (360p) or 6 credits/s (720p); Extend 1 credit/s (360p) or 3 credits/s (720p) added; upscale to 1080p free for 1-10 s (1 credit per extra second); 4K Ultra only (50 credits flat for 1-10 s). So an 8 s 720p clip = 24 credits; 10 s = 30; 10 s at 360p = 10. Free tier = 50 credits/day (no rollover); Plus +200/mo, Pro +1,000/mo, Ultra $100 +10,000/mo, Ultra $200 +25,000/mo. Costs "subject to change"; check prompt-box Settings. — [Flow Help: Manage credits](https://support.google.com/flow/answer/16526234?hl=en); [flow.google.com](https://flow.google.com/)
- No separate credit charge for saving a Character or custom voice is documented; Character images are generated with Nano Banana models (per-generation cost not retrieved).
- Plan: free accounts get Characters, Avatars, Ingredients, Frames, Scenebuilder with Omni 1.2 Flash up to 10 s; Plus+ adds 11-15 s, Extend (with Ingredients), upscale; non-subscribers "may not be able to generate videos" at peak hours roughly 2-5 PM UTC. — [flow.google.com](https://flow.google.com/); [Flow Help: Credits](https://support.google.com/flow/answer/16526234?hl=en)
- Model retirement: Veo 3.1 Fast, Veo 3.1 Quality and Omni Flash 1.1 retire Dec 5, 2026; Veo Extend retired Nov 5, 2026. Gemini API routes omni-1.1 to 1.2 on Dec 3, 2026. — [Flow Help: Credits](https://support.google.com/flow/answer/16526234?hl=en); [AI Studio Omni docs](https://aistudio.google.com/docs/omni)
- Pricing signal for 720p API use: $0.07 per second, "30% lower than 1.1." — [Google blog](https://blog.google/innovation-and-ai/technology/developers-tools/introducing-gemini-omni-1-2-flash/)

### Inferences
- A practical 8-10 s shot plan: one Character per speaker (max 2 on screen per the API limit), name + voice attached, `@Name` in prompt, "single continuous shot" if you want no cuts, and 10 s at 720p = 30 credits (about 1.7 clips of 10 s per day on the free 50 credits; 360p drafts at 10 credits allow about 5).
- To chain shots, use Extend (Plus+) or re-pass the same Character and a saved frame; use saved frames ("Save frame" from the video player) as new ingredients/start frames to keep outfit and background.

### Gaps
- No official Flow-UI statement of max characters per generation (only the API's 2-character/3-images-each figure and 6-image total). Whether the UI allows the same numbers is unverified.
- No independent, quantified test of voice stability across many clips found (see section 5).

## 4. Restrictions: regions (Indonesia, EEA), likeness, minors, 2D/anime

### Takeaway
Indonesia is on the official supported-countries list, and Avatars are unavailable only in the EEA, UK and Switzerland, so Indonesia has both Flow and Avatars per the docs. Real-person, minor and editing-speech restrictions apply globally. Illustrated/anime/2D styles are shown to work in Omni/Flow by Google's own examples and hands-on guides, but there is no official "2D character" statement.

### Cited Findings
- Indonesia is in "Supported countries & territories" (Google Flow desktop and mobile app), 18+. Indonesian is a supported language. — [Flow Help: Where you can use Flow](https://support.google.com/flow/answer/16353544?hl=en)
- Avatars: "Avatar is not available in: The EEA, The UK, Switzerland. All users outside of these regions can use avatars." — [Flow Help: Avatar](https://support.google.com/flow/answer/17102997?hl=en); same in [Where you can use Flow](https://support.google.com/flow/answer/16353544?hl=en). So Indonesia: avatars supported per docs (no Indonesia-specific testing found).
- Editing uploaded videos is unsupported in the EEA, Switzerland and UK. AI credit purchase unavailable in Japan. — [Where you can use Flow](https://support.google.com/flow/answer/16353544?hl=en)
- Unsupported in any region: "Editing uploaded videos of identifiable minors. Generating videos of prominent people. Editing or generating what people say in uploaded videos" (changing speech, adding dialogue, dubbing). You can instead generate a new video from a prompt to add speech. — [Where you can use Flow](https://support.google.com/flow/answer/16353544?hl=en)
- API: "Uploading and editing images containing certain recognizable people is not supported"; images containing minors not supported in the EEA, Switzerland, UK; safety filters "vary by region"; SynthID invisible watermark on all outputs. — [AI Studio Omni docs](https://aistudio.google.com/docs/omni); [Flow Help 16935308](https://support.google.com/flow/answer/16935308?hl=en)
- Avatar data cannot be shared via Flow Tools or public links; Flow's "share" gives anyone with the link access to the creation (optionally with "Include inputs"). — [Flow Help 17102997](https://support.google.com/flow/answer/17102997?hl=en); [Flow Help 16935308](https://support.google.com/flow/answer/16935308?hl=en)
- Illustrated/2D: Google's AI Studio prompt examples include "Make this video anime" and an image-to-video example turning a drawing into realistic footage; the 1.2 announcement demo is "a 15-second animated scene" with four voiced characters (voice routed per character). — [AI Studio Omni docs](https://aistudio.google.com/docs/omni); [Google blog](https://blog.google/innovation-and-ai/technology/developers-tools/introducing-gemini-omni-1-2-flash/)
- Hands-on anime: an AutoWeeb guide (API preview era, uses `<FIRST_FRAME>`/`<IMAGE_REF_N>` tags) reports anime works best when a polished anime starting image is the "visual contract," says Omni "can look over-animated" on quiet scenes, adds dialogue even unprompted unless "no dialogue" is written, and that copyrighted-character prompts get blocked. — [AutoWeeb](https://autoweeb.com/blog/how-to-create-anime-videos-with-google-omni-flash). CONFLICT: that guide uses `<FIRST_FRAME>`-style control tags, whereas Google's current docs say "Do not include control strings (such as `<FIRST_FRAME>`...) ... These tags are deprecated and unsupported in future models." — [AI Studio Omni docs](https://aistudio.google.com/docs/omni). Treat the tag syntax as outdated; use natural language / `@Name`.
- YouTube tutorials exist on "2D cartoon movies with Google Flow Omni Flash" and "Omni 1.1 Characters & Voice Tested" ([2D cartoon video](https://www.youtube.com/watch?v=oTcqQplFudQ), [Characters & Voice tested](https://www.youtube.com/watch?v=yRM1df108G0&vl=en-US)); [snippet only, not watched].
- Flow is for 18+ users. — [flow.google.com](https://flow.google.com/)

### Inferences
- A 2D/anime Character should work by uploading/generating 1-2 anime-style reference images (Characters tab) and calling `@Name`; there is no documented exclusion of non-photoreal characters. Original characters avoid IP/likeness filters.
- Do not rely on a real-person lookalike or minor-depicting photo as a reference; prefer original illustrated or fictional characters.

### Gaps
- No official statement that Characters support non-photoreal/2D styles; no official policy text found on fictional minors or stylized minors.
- No Indonesia-specific hands-on report on Avatars or voices was found.

## 5. Known failure modes (voice drift, outfit drift) and mitigations

### Takeaway
Google admits ongoing limits ("fast sports action, rapid script changes and complex physics") and says "a prompt cannot guarantee clean speaker assignment" is a third-party view; community reports of voice not staying consistent exist but are older/snippet-level. Mitigations: attach the voice via Character/`@Voice`, keep one speaker per voice reference, state the speaker-voice binding in the prompt, re-pass references on every clip/extension, and fall back to external TTS for strict voice control.

### Cited Findings
- Google: "While development is ongoing to further improve things like fast sports action, rapid script changes and complex physics..." (limits of 1.2). — [Google blog](https://blog.google/innovation-and-ai/technology/developers-tools/introducing-gemini-omni-1-2-flash/)
- Voice constraints: voice reference must be single-speaker; voice references only for ingredient-based video; "Voice editing is not supported"; audio references unsupported in the API. — [Flow Help 16353334](https://support.google.com/flow/answer/16353334?hl=en&co=GENIE.Platform%3DDesktop); [AI Studio](https://aistudio.google.com/docs/omni)
- Dialogue limits: cannot add dialogue when extending an uploaded video; multi-turn extension of generated video works. — [AI Studio](https://aistudio.google.com/docs/omni)
- Extension/outfit drift mitigation: only the last 10 s are used as context; re-mention or re-reference characters seen earlier. — [AI Studio](https://aistudio.google.com/docs/omni)
- Multi-speaker: "a prompt cannot guarantee clean speaker assignment on the first render"; recommends named speakers, exact quoted lines, positions, silent listener, "Keep each voice attached to the same person throughout," and checking each line against the clip. Contains the caution that text-only prompts do not "upload, clone, or select a recorded voice." — [Atlas Cloud](https://www.atlascloud.ai/blog/tips/gemini-omni-1.2-flash-multi-speaker-dialogue) (third party, a model-hosting vendor)
- Community [snippet only]: r/GoogleFlow thread "how do you keep the same character" says "the character reference, voice, and description have to be added or managed separately each time" ([Reddit](https://www.reddit.com/r/GoogleFlow/comments/1v0nrni/google_flow_tools_how_do_you_keep_the_same/)); r/VEO3 says "generating the voice in ElevenLab and edit in post is the only way around for now" for voice consistency ([Reddit](https://www.reddit.com/r/VEO3/comments/1tssldu/voice_consistency_how/)). These are excerpts, undated here, and the r/VEO3 one likely predates Flow's voice feature (Veo era); they conflict with Google's claim that Characters keep voice "strictly consistent." Could not fetch the full threads (Firecrawl does not support Reddit).
- Third-party tool caution: Higgsfield etc. note small drift under extreme style shifts (not Flow). Not relevant to Flow; excluded.

### Inferences
- Voice drift risk is highest when (a) no voice is attached, (b) two speakers are in one clip, (c) the extension starts from an uploaded talking video, or (d) the prompt text contradicts the character's reference (accent, age, outfit).
- For strict voice identity (e.g., Indonesian narration) the safest fallback is to generate clips silent/"no dialogue" and add voice from an external TTS in post. This is a workflow inference; Flow also has a "Return silent videos" project setting. — [Flow Help 16935308](https://support.google.com/flow/answer/16935308?hl=en)

### Gaps
- No controlled test quantifying voice drift or outfit drift across many 8-10 s Flow clips; no official known-issues list for Characters.
- Could not read the full Reddit/YouTube/Facebook sources; their claims are unverified excerpts.
